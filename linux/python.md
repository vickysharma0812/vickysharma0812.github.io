Python is by default installed on your system. You can check the version of python by using the following command.

```bash
python --version
```

## Python package manager

Installing  pip

```bash
sudo pacman -Sy python-pip 
```

Installing pipx
  
```bash
sudo pacman -Sy python-pipx
```
